# 하네스 목적 (R2)

| 항목 | 확정 |
|---|---|
| 매번 달라지는 것 (입력 단위) | **서비스 1개.** 예: 이번 Element_Metro, 다음 Bio_Metro. story-work 1~9단계를 전부 돈다 |
| 하네스 사용자 | **운영자(본인) 1명.** 사람 승인도 이 1명이 한다 |
| 하지 않는 것 | 노선 1개 추가. PRD상 JSON만 추가하면 되는 일이라 하네스 밖 |

## 완료 기준 (한 문장)
PRD 14장 체크 항목 15개 중 자동 판정 항목은 전부 통과, 나머지 항목은 사람 체크로 미체크 0개, Vercel 배포 URL이 HTTP 200을 응답한다.

- 체크 항목 15개 = 입력 감각 6 + 화면과 흐름 5 + 확장성 4
- Na 항목은 story-service.md "PRD와 다른 결정"에 따라 바뀐 문장을 쓴다
- 자동/사람 분류는 R5에서 정한다
