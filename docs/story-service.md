# Element_Metro — 서비스 맥락 ("무엇을 위한 일인가")

출처: docs/prd.md (2026-11-13). MVP 1차 범위만 다룬다.
이 문서는 **판정 기준**이다. 작업 순서(docs/story-work.md)의 재료로 쓰지 않는다.

## 유저스토리
1. 릴스를 본 방문자가 가입 없이 링크 하나로 특정 노선·모드에 바로 들어가 한 판을 달린다. (PRD 3-1, 5장 URL)
2. 방문자가 종착역에서 기록을 복사하거나 1080×1920 결과 카드로 저장해 공유한다. (3-1, 6-5)
3. 학생이 역마다 원소를 입력하며 노선을 완주하고, 끝난 뒤 틀린 역을 다시 보고 지난 최고 기록과 비교한다. (3-2, 6-5, 6-6)
4. 과학 교사가 수업 시작 5분 활동이나 단원 복습에 쓸 노선을 고른다. (3-3)
5. 운영자(사이음)가 화면 코드를 고치지 않고 노선 JSON 파일만 추가해 새 노선을 연다. (3-4, 6-7)

## 이 서비스에서 어기면 안 되는 것
- **N1. 개인정보는 최소한만, 본인이 고를 때만 받는다.** 로그인 없음. 기본 기록은 사용자 브라우저에만 저장. 결과 화면에서 사용자가 **'랭킹에 올리기'를 직접 누른 경우에만** 학교(NEIS 학교코드·학교명)와 닉네임, 그 판의 기록을 서버(Supabase)에 저장한다. 실명·학년·반·연락처·기기 식별자는 받지 않는다. NEIS API 키는 서버(Edge Function)에만 둔다. (PRD 7장·13장을 운영자 결정으로 변경, 2026-11-13)
- **N2. 원소 이름은 아래 표기 기준을 따르고, 다른 이름은 오답으로 끊지 않는다.** 별칭은 정답으로 인정하고 공식 표기를 안내한다. (PRD 9장 결정 4, 13장 표기)
