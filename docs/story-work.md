# Element_Metro — 작업 흐름 ("실제로 어떻게 했는가")

AI 없이 손으로 했던 마지막 경험을, 했던 순서 그대로 적는다.
docs/story-service.md의 N1·N2는 판정 기준이며 이 문서의 재료가 아니다.

## 실제 순서
1. 나는 uibowl에서 경쟁사 레퍼런스를 수집한다.
2. 나는 레퍼런스를 분석하고 우리 서비스에 반영할 부분을 가져온다.
3. 나는 분석 내용을 토대로 우리 서비스 화면 설계 문서를 구체화한다.
4. 나는 Figma에 레퍼런스와 화면 설계서를 반영한 UI 키스크린 2~3개를 390×844로 그린다.
5. 나는 내부 관계자들과 협의한 뒤 컨셉 시안을 확정한다. **(멈칫)** **(넘김 → 내부 관계자: 운영자 1명)**
6. 나는 확정 시안을 기반으로 디자인 토큰과 컴포넌트를 만들고 화면 디자인에 들어간다.
7. 나는 완성 시안의 토큰·컴포넌트가 우리 가이드를 위반하지 않았는지 검토한다. **(멈칫)**
8. 나는 확정 화면과 토큰을 보고 AI에게 정적 웹앱 코딩을 시킨다. **(넘김 → 코딩 AI)**
9. 나는 PRD 14장 체크리스트를 직접 눌러 보며 확인한다. **(멈칫)**
