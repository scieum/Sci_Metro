# Organism_Metro 화면 설계서 (S1)

토큰·컴포넌트·내비게이션은 Science_Metro 공통 (docs/design.md). 바뀌는 것만 적는다.
데이터 초안: `app/data/organs.json` (기관 61역), `app/data/lines/*.json` (service_id = organism, 12노선).

## 홈
- Science_Metro 홈의 서비스 목록에 `Organism_Metro · 운행 중` 줄 추가. 썸네일 = 소화선 노선도.
- 설명: "기관계 노선 12개에서 기관을 달려요".

## 노선 선택
- 주소 `/organism`. 머리글 `Organism_Metro / 어느 노선을 탈까요?`
- 탭 2개: **기초 8** (중2 동물과 에너지 · 중3 자극과 반응) / **심화 4** (생명과학Ⅰ). 주기율표 학습 탭은 없음.
- 승차권: 노선도 썸네일(가로 노선, 2줄까지 꺾임) + 노선 이름 + 난도 점 + `6역 · 입 → 항문 · 음식물이 지나가는 소화관`.
- 승차권을 누르면 모드 창(바텀시트): 연습 · 이름 쓰기 · 순서 쓰기 · 섞어 쓰기.

## 플레이
- 위: 노선 안내판 + **몸 지도** — 몸 실루엣·심장·콩팥·눈·귀 그림 위에서 실제 기관 위치를 따라 노선이 지나간다 (운영자 요청 2026-11-14). 지난 역은 이름 표시, 이번 역은 파란 원, 남은 역은 번호만.
- 가운데: 이번 역 카드 = `3번째 역` + **설명 문장** (예: "위액 속 펩신이 단백질을 분해하고, 염산이 세균을 없애요") + 이름 입력칸. 양옆에 지난 역(이름)·다음 역(?) 작은 칸.
- 순서 쓰기 모드: 설명 문장 자리에 "다음 역은?" — 노선도만 보고 순서를 떠올린다.
- 별칭 정답(예: 허파꽈리 → 폐포)은 정답 + 공식 이름 안내 토스트.

## 결과
- Element와 같은 틀: 종착역 도착 띠, 시간·정확도·평균 타수, 도장 3개.
- 다시 볼 역 = **기관 이름 + 설명 한 줄** 카드 (R3).
- 결과 카드 PNG: 미니 주기율표 대신 기관계 노선도.

## 내 기록
- 기존 기록 페이지에 Organism 노선 기록이 섞여 나온다(노선 색 점으로 구분). "자주 틀린 원소" → "자주 틀린 역".
