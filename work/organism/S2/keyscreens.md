## 장면 그림 (Higgsfield gpt_image_2_6, 2026-11-14)
SVG 직접 그림은 운영자 반려("너무 짜침") → 생성 이미지 5장으로 교체. 원본: `app/public/organism/{body,heart,kidney,eye,ear}.png`, Figma 같은 페이지 왼쪽 `scene/*`.
역 좌표는 이미지 픽셀 좌표(몸 688×1024, 심장·콩팥 1024×1024, 눈·귀 1024×688)로 찍었다. 노선은 그림 위에 흰 테 + 노선 색 선으로 얹는다.
- 몸 그림이 아이 얼굴이 있는 캐릭터풍이다. 식도는 따로 안 보이고 기관·척수와 겹친다.
- 심장 그림의 왼쪽 폐정맥이 우심방 쪽으로 들어가게 그려져 있다(해부학 오류) → 순환선은 오른쪽 폐 경로만 쓴다. 교사 검수 필요.

## 지도 = 실제 몸 (운영자 요청 2026-11-14)
Element의 주기율표 자리에 **기관이 있는 실제 그림**을 깔고, 노선은 그 위의 실제 위치를 따라간다.
| 장면 | 노선 |
|---|---|
| 몸 실루엣 (앞모습, 뇌·폐·심장·간·위·창자·콩팥·방광·척수) | 소화선 · 호흡선 · 반응선 · 반사선 · 산소 여행선 |
| 심장 4방 + 폐 + 온몸 | 순환선 |
| 콩팥 단면 + 대동맥 + 방광 | 배설선 · 네프론선 |
| 눈 단면 | 시각선 |
| 귀 단면 | 청각선 |
| 뉴런 (그리지 않음, S3) | 뉴런선 · 반사궁선 |

- 지난 역: 노선 색 원 + 이름표 / 이번 역: 파란 원 + `?` / 남은 역: 흰 원 + 번호 / 틀린 역: 빨간 테.
- 지도는 노선이 지나는 부분만 잘라 보여 준다 (소화선 = 몸통, 시각선 = 눈 단면 전체).
- 몸 그림·기관 위치는 **교사 검수 전 초안**.
